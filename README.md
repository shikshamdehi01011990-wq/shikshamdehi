# ShikshamDehi Website

Professional Next.js landing website for ShikshamDehi.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Vercel will detect Next.js automatically.
4. Deploy.

Before launch, replace the placeholder WhatsApp number and email in `app/page.js`, and add your real logo/photos if desired.
